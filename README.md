# TypeQuest

A gamified typing trainer — from learning hand placement to high-speed tests.

**Status:** Phase 1 — typing engine, Speed Test, results screen, Neon Cyber + Minimal Calm themes.

## Run it

```bash
npm install
npm run dev        # http://localhost:3000  → /test
npm test           # engine unit tests (Vitest, headless)
npm run typecheck
npm run build
```

Requires Node 20+.

## Architecture

- `src/engine/` — the typing engine, pure TypeScript with no React. Every mode, theme and challenge sits on top of it.
  - `typingEngine.ts` — state machine (chars, words, combo, timing via `performance.now()`), typed events.
  - `inputCapture.ts` — hidden `<input>` adapter (IME/mobile, paste blocked). The only engine file that touches the DOM.
  - `metrics.ts` — net/gross/raw WPM, accuracy, consistency, per-second samples, per-key stats.
  - `lessonGen.ts` — seeded word generation, key-restricted drills, adaptive weak-key weighting.
  - `replay.ts` — re-runs a keystroke log through a headless engine (anti-cheat, ghosts, replays).
- `src/themes/<name>/` — theme plugins: a data `config.ts` + `effects.ts` that only listens to engine events.
  Colors in `config.ts` become CSS variables (`themeCss()` in `registry.ts`), mapped to Tailwind in `globals.css`.
- `src/components/typing/wordsRenderer.ts` — imperative DOM renderer; typing never re-renders React.
- `src/stores/` — Zustand (settings, local history/personal bests) persisted to localStorage.
- `src/modifiers/types.ts` — challenge modifier contract (implemented in Phase 6).

Key sounds are generated by `npm run gen:sounds` (`scripts/gen-sounds.mjs` → `public/sounds/`).

## Keys

`Tab` / `Esc` restart · `Enter` next test (on results) · Ctrl+Backspace deletes a word.
