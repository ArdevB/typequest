# TypeQuest

A gamified typing trainer — from learning hand placement to high-speed tests.

**Status:** Phase 7 — Speed Test, Learn, Practice, accounts/XP/leaderboards, challenges/achievements/streaks, Pixi game modes with a Weekly Boss and friend ghost races, Chaos modifiers, unlockable themes, Keeby the mascot, music and game sound, Dvorak/Colemak, and online chaos/practice.

## Run it

```bash
npm install
npm run dev        # http://localhost:3000  → /test
npm test           # engine unit tests (Vitest, headless)
npm run typecheck
npm run build
```

Requires Node 20+.

## Architecture

- `src/engine/` — the typing engine, pure TypeScript with no React. Every mode, theme and challenge sits on top of it.
  - `typingEngine.ts` — state machine (chars, words, combo, timing via `performance.now()`), typed events.
  - `inputCapture.ts` — hidden `<input>` adapter (IME/mobile, paste blocked). The only engine file that touches the DOM.
  - `metrics.ts` — net/gross/raw WPM, accuracy, consistency, per-second samples, per-key stats.
  - `lessonGen.ts` — seeded word generation, key-restricted drills, adaptive weak-key weighting.
  - `replay.ts` — re-runs a keystroke log through a headless engine (anti-cheat, ghosts, replays).
- `src/themes/<name>/` — theme plugins: a data `config.ts` + `effects.ts` that only listens to engine events.
  Colors in `config.ts` become CSS variables (`themeCss()` in `registry.ts`), mapped to Tailwind in `globals.css`.
- `src/components/typing/wordsRenderer.ts` — imperative DOM renderer; typing never re-renders React.
- `src/stores/` — Zustand (settings, local history/personal bests) persisted to localStorage.
- `src/modifiers/types.ts` — challenge modifier contract (implemented in Phase 6).

Key sounds are generated by `npm run gen:sounds` (`scripts/gen-sounds.mjs` → `public/sounds/`).

## Keys

`Tab` / `Esc` restart · `Enter` next test (on results) · Ctrl+Backspace deletes a word.

## Learn mode

- `src/lessons/` — the lesson catalog (6 units, 32 lessons), text builders, star rating and unlock rules.
- `src/components/keyboard/` — on-screen keyboard (ANSI geometry, finger colors) and `keyboardGuide.ts`, which follows the engine to highlight the next key, Shift and finger.
- `src/components/hands/Hands.tsx` — SVG hands drawn on the keyboard's scale.
- Lesson word list: SCOWL (see `src/engine/words/SCOWL-LICENSE.txt`).

## Accounts (Supabase)

Without Supabase settings the app runs in guest mode (everything saves in the browser). To switch accounts on:

1. Create a project at [supabase.com](https://supabase.com).
2. In the SQL editor, run `supabase/migrations/20261016000000_core.sql` (or `supabase db push` with the Supabase CLI).
3. Copy `.env.example` to `.env.local` and fill in the URL, the anon/publishable key and the service-role/secret key
   (Project Settings → API). The service key stays on the server; never prefix it with `NEXT_PUBLIC_`.
4. In Authentication → URL Configuration, set the Site URL (e.g. `http://localhost:3000`, later your Vercel URL) and add
   `<site>/auth/callback` to Redirect URLs.
5. Restart `npm run dev`. On Vercel, add the same three variables in the project settings.

How scores stay honest: the browser sends only the test settings, the word seed and the keystroke log. The API
(`src/app/api/runs`) regenerates the words, replays the log through the same typing engine, rejects pasted text and
impossible keystroke timing, and writes the result with the service role. Clients can't write runs, XP or ranks
directly (Row Level Security). Guest runs and lessons are kept locally and re-verified the same way after sign-up.

- `supabase/migrations/` — schema, RLS policies, leaderboard and server-only write functions.
- `supabase/tests/run.sh` — applies the migrations to a local Postgres (with Supabase stubs) and runs policy tests.
- `src/server/` — run/lesson validation (`validateRun.ts`) and database writes (`record.ts`).
- `src/lib/progression.ts` — XP per run/lesson, level curve, ranks (Bronze < 30, Silver 30+, Gold 50+, Diamond 70+,
  Master 100+ WPM, from the average of your best three 30s+ time tests).

## Challenges, achievements, streaks (Phase 4)

Database: run `supabase/migrations/20261016020000_challenges.sql` after the core migration. Optionally enable the
`pg_cron` extension and run `supabase/cron/daily_challenge.sql` to create each daily challenge at midnight Nepal time
(the app also creates today's challenge on demand, so this is only a safety net).

- `src/challenges/` — daily rotation helpers, the six skill challenges (tiers, setup, pass/fail), live guards.
- `src/achievements/` — achievement catalog (mirrored in the migration; a test keeps them in sync) and unlock rules.
- `src/server/validateChallenge.ts` — replays challenge attempts with the challenge's own seed and rules.
- Streaks update on any saved activity (`touch_streak`); a streak freeze covers one missed day.

## Game modes (Phase 5)

Database: run `supabase/migrations/20261016030000_games.sql` (adds `game_runs`, `record_game`, `game_leaderboard`).

- `src/games/` — pure TypeScript game simulations on top of the typing engine (no React, no Pixi). Each sim steps in
  fixed 1/60 s ticks of game time, so the same seed + keystroke log always plays out the same way.
- `src/games/live.ts` — runs a sim in real time; each keystroke is applied at the exact game time it was stamped with.
- `src/games/registry.ts` — `replayGame()` is what the server uses (`/api/games`) to recompute the score before saving.
- `src/games/render/` — Pixi renderers that only read `sim.state` and visual events (`drainFx()`).
- `src/components/games/GamePlayer.tsx` — mounts Pixi (lazy-loaded), the HUD, word strip, sounds and results.
- Stickman Duel: short words jab, 4–5 letters kick, longer words uppercut, every 5th clean word in a row is a spinning
  special; the finishing blow plays in slow motion with letterbox bars, a camera push-in and a K.O. title.
- Racing saves your fastest finished race in this browser and replays it as a ghost car.

## Phase 6: practice, chaos, weekly boss, unlockables, mascot

Database: run `supabase/migrations/20261016040000_weekly_boss.sql` (allows `weekly-boss` game runs, per-week "best",
and `weekly_boss_leaderboard`).

- **Practice** (`/practice`, `src/components/practice/`): key heatmap (mistakes or slow keys), weakest keys, a
  weak-key drill and single-key drills. Uses your account's key stats when signed in, otherwise this browser's.
  Drills feed the key stats but never count as speed tests.
- **Chaos** (`/chaos`, `src/modifiers/`): stackable modifiers built on the `ChallengeModifier` contract —
  `transformText` (Backwords, rAnDoM cAsE), `renderEffect` (Mirror, Fog, Earthquake, Tiny Text, Heat Timer) and
  `onError` (Sudden Death). Multipliers multiply. Chaos bests are kept in the browser.
- **Weekly Boss** (`/play/weekly-boss`, `src/games/weekly.ts`): a tougher three-eyed boss; everyone gets the same seed
  for the week (Monday 00:00 Nepal time reset) and a weekly twist derived from the seed, so the server's replay
  sees the same words. The server only accepts this week's (or last week's) seed.
- **Race a friend** (`src/games/share.ts`): after a race, "Challenge a friend" copies a link carrying the seed and your
  progress trace; opening it races your ghost on the exact same words.
- **Unlockables** (`src/unlocks/catalog.ts`): Retro Arcade (10 speed tests or level 3), Space Shooter (3 game wins or
  level 6), Inferno (beat a Weekly Boss), plus Keeby outfits (headphones, shades, crown). New unlocks pop a toast.
- **Keeby** (`src/components/mascot/`): an SVG keycap mascot driven by engine events through data-attributes (no React
  re-render per key): bobs, grins at clean words, jumps on combos, winces at mistakes, naps when idle, and gives one
  specific tip after each test. Can be turned off in Settings; reduced motion stills it.
- Polish: active nav link, mobile menu, 404 page, landing page links to everything.

## Phase 7: fight scene, sound, layouts, online chaos & practice

Database: run `supabase/migrations/20261016050000_chaos_practice.sql` (chaos runs + leaderboard, practice key stats + XP).

- **Stickman Duel** (`src/games/render/duel.ts`): outlined fighters with headband ribbons, a rooftop at night with
  parallax city, rain and a lamp; hit-stop, manga impact frames, spark stars, damage numbers and a combo counter;
  a tracking camera; varied moves (jab/cross, kick/high kick/sweep, uppercut, spin kick, flying-kick finisher);
  a ragdoll K.O. with bounces. New rule in the sim (`src/games/duel.ts`): finish a word just as the rival strikes
  (it telegraphs with a "!") to **parry** — no damage, and you riposte. Results wait for the K.O. scene to finish.
- **Sound** (`scripts/make-audio.py` → `public/sounds/sfx`, `public/music`): every effect and music loop is
  synthesized from code (no samples). Music per theme plus a battle track in games (off by default; Settings →
  Music & game effects). Game effects: punches, parries, KO bell, lasers, explosions, slams, roars, engine.
  Re-generate with `python3 scripts/make-audio.py` (needs numpy, scipy, ffmpeg).
- **Layouts** (`src/engine/layouts/`): Dvorak and Colemak are built on QWERTY's physical keys, so fingers stay the
  same. Lessons teach the keys at the same positions (Dvorak's first lesson is U and H), and the keyboard guide,
  hands and practice follow the layout chosen in Settings. Lesson saves carry the layout for server checks.
- **Online chaos**: `/api/chaos` rebuilds the words (seed + text modifiers) and the rules (`onError`; the Heat Timer
  now uses `engine.penalize()`), replays the run and saves the score with XP. "Chaos masters" board on `/chaos`.
- **Online practice**: `/api/practice` rebuilds the drill (`src/practice/drills.ts`), replays it, merges the key
  stats into the account and gives a little XP.
